# Mithrilyc

Primera vertical slice jugable de un deckbuilder roguelike de criaturas míticas.

## Qué incluye

- Selección entre Dragón, Medusa y Minotauro.
- Identidad de juego distinta para cada criatura: Calor, Mirada y Furia.
- Mapa de decisiones con combates, élites, santuarios, eventos y jefe.
- Combate por turnos con energía, mano, descarte, estados y bloqueo.
- Recompensas de cartas, reliquias y progresión dentro de la partida.
- Final de victoria/derrota y reinicio rápido.

## Ejecutarlo

No necesita instalación ni servidor: abre `index.html` en un navegador moderno.

## Siguiente fase de diseño

1. Probar el bucle completo con jugadores reales.
2. Ajustar valores de daño, vida, energía y recompensas.
3. Definir dirección artística definitiva y nombre comercial.
4. Elegir motor y preparar exportaciones para web, PC y Android.
5. Separar contenido de cartas/enemigos de la lógica para ampliar el juego sin perder equilibrio.
